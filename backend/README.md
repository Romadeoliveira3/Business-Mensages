# Backend (Python)

This directory is reserved for the future Python backend implementation. Add your FastAPI, Flask, or other server code here to expose APIs that power the Business Messages Manager interface.

Suggested structure:

- `app/` – Python application modules
- `requirements.txt` – Backend dependencies
- `tests/` – Automated backend tests

Until the backend is implemented, this folder serves as a placeholder to keep the project structure aligned with the new frontend/backend separation.
